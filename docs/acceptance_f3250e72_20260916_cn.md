## 后续探针代码加固（不属于 f3250e72 镜像）

复核 Put 结果确认循环发现独立验收漏洞：RPC 返回成功但响应校验失败时，原循环仍进行 Get 确认，可能掩盖错误集群 ID、未推进 revision 等错误成功响应。提取 `resolveProbePut`，将这种成功响应语义错误改为立即失败；仅 SDK 返回错误时保留原读取确认路径。共享 command deadline、50ms 重试间隔、SDK 调用计数以及原验收门限不变。

对照 `/root/etcd/client/v3/retry_interceptor.go`：etcd SDK 在上下文期限耗尽时直接返回错误，不会自动给确认读取延长期限。本轮确认读取立即超时与共享期限耗尽一致，不应当通过给 Get 新增独立预算把失败改成通过。

新增测试覆盖空响应/响应头、错误集群、未推进 revision、不请求的 PrevKv 均立即失败，以及正常成功、丢失响应后确认成功、确认未观察到写入后的重试、过期期限不延长。定向 race 测试与 vet 已通过；全探针 race 测试另行跟踪。此修改尚未发布或部署，不能解释或修复此次 TiKV Raft 慢写。
